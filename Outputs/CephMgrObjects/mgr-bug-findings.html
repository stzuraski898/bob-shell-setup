How Whiteboard Defense bugs were found

  • Method: For each object: (1) read the implementation and extract a precise intent model (invariants, state transitions, threading contract, lifecycle); (2) compare intent against the actual code line by line; (3) classify each gap as DIVERGED (confirmed mismatch), UNGROUNDED (possible risk), or DOC (comment staleness).
  • Scope: 27 objects from src/mgr/. Source artefacts in Outputs/Intents/ and Outputs/CephMgrObjects/WhiteboardDefense/.
  • Scoring: each object rated 1–5 on unit-test reproducibility, impact, and ease of fix. Composite max = 15. Objects with no confirmed DIVERGED item are Tier 2 (hardening) or Tier 3 (clean) regardless of score.
  • Filed trackers: MgrCap (#81015–#81017), PerfCounterInstance (#81018–#81020), ThreadMonitor (#81336–#81338), PyModule (#81339), MgrOpRequest (#81340–#81341).
