1 High-Level Architecture & Mental Model

One-Line Summary

A Bash launcher that reads a structured prompt source (directory of .md files or a legacy file), generates ephemeral per-agent wrapper scripts, optionally syncs reference material to a remote host over SSH, then opens one Tilix terminal tab per agent — each landing in its own git worktree and running an isolated bob run or bob chat session.

Directory-based Prompt Loading (Preferred Path)

Inputs/Prompts/history-assessment/ ├── 01-DaemonKey.md ← frontmatter: tracker: https://tracker.ceph.com/12345 ├── 02-MgrCap.md ← frontmatter: tracker: none ├── 03-ClusterState.md ← no frontmatter block (url defaults to "none") │ ↓ load_from_directory() per-file state machine: │ │ first_fence=1 ─── see "---" ──▶ in_frontmatter=1, first_fence=0 │ in_frontmatter=1 ─ see "---" ──▶ frontmatter_done=1, in_frontmatter=0 │ in_frontmatter=1 ─ match "^tracker: (.*)" ──▶ url = stripped value │ frontmatter_done ─ accumulate body lines (skip leading blanks) │ EOF ─ sed-trim trailing whitespace; push (url, body) to parallel arrays │ ↓ Sorted output (lexicographic filename order controls agent assignment) tracker_url[0] = "https://tracker.ceph.com/12345" prompt[0] = "…01 body…" tracker_url[1] = "none" prompt[1] = "…02 body…" tracker_url[2] = "none" prompt[2] = "…03 body…"

Key Invariants

  • One worktree per agent — no two agents share a working directory or branch when worktrees enabled.
  • All scripts staged before any Tilix tab opens — agent_scripts[] fully populated in one loop, then Tilix launched.
  • API key never in argv — injected via export inside the heredoc; invisible to ps aux.
  • Tab stays open on any bob failure — exec bash replaces the runner process, preserving PTY.
  • --dry-run is completely side-effect-free — no SSH, no file writes, no Tilix invocations; exits at line 291.
  • Minimum 1 agent — even with no instruction file, AGENT_COUNT = max(1, 0) = 1 opens an interactive bob chat tab.
  • Filename ordering controls agent assignment — find … -name '*.md' | sort -z is lexicographic; numeric prefixes (01-, 02-) give deterministic launch order.

2 Architectural Decisions & Trade-offs

Decision Alternative Considered Why This Choice Cost / Risk
Directory of .md files as instruction source (preferred) Single monolithic instruction file One file per agent = easy add/remove/reorder. YAML frontmatter in each file keeps tracker URL co-located with its prompt. Filename prefix (01-) provides explicit ordering without a separate manifest. Requires find + sort; parser state machine per-file adds complexity. Non-.md files silently ignored (by design).
YAML-style frontmatter parsing in pure Bash Require a YAML tool (yq, python3 -c) Zero external dependencies. Script must run on any machine with Bash ≥ 4.4. The frontmatter schema is intentionally minimal (only tracker: key recognized). Parser is hand-rolled: only parses tracker:; other keys silently ignored. No multi-line YAML values, arrays, or anchors. Misformed frontmatter (e.g., trailing space before ---) passes through to body.
Legacy file formats preserved (Format A: 2-line pairs; Format B: ## N. sections) Drop legacy; require directory format only Backward compatibility with existing bob-instructions hand-authored files and Whiteboard Defense prompt outputs from other pipeline scripts. Format B detection is a heuristic regex (^## [0-9]+\. or ```markdown) — could misfire on markdown files with those patterns outside of Format B intent.
Git worktrees (~/ceph-agent-N per agent) N full git clones or single shared repo Shared object store — no multi-GB history duplication. Agents can commit, stage, and switch files concurrently without .git/index.lock collisions. Branch isolation is enforced by Git itself. Shared .git: a git gc on the primary repo can transiently block all worktrees. Git enforces that one branch can only be checked out in one worktree at a time.
Tilix multi-tab via DBus tmux / headless daemons / screen Human-in-the-loop: developer sees live agent reasoning, diffs, and compiler output in adjacent tabs. Full interactive PTY retained for manual intervention. Visual UX is the primary use case. Requires graphical session + Tilix installed. Fails entirely in headless/CI. DBus window registration has a timing dependency (addressed with a 2s sleep heuristic).
Two-phase script staging (cat > /tmp/bob-agent-N.sh → ssh -t … bash /tmp/…) Single ssh -t host "export KEY=…; bob run …" Eliminates multilevel nested quoting across local heredoc → SSH → remote shell layers. Keeps the interactive PTY channel clean — no initialization output corrupts the TTY. The staging channel (non-interactive) and execution channel (interactive PTY) are cleanly separated. Cleartext API key in /tmp between staging and execution. Two SSH round-trips per agent instead of one.
API key via BOBSHELL_API_KEY env var OAuth web flow / SSH port-forward / CLI arg / .env file Remote server has no browser for web flows. Port-forwarding adds operational complexity and latency. Env var is invisible in process argument lists (ps aux, /proc/PID/cmdline). Key lives in cleartext inside /tmp/bob-agent-N.sh until the remote shell reads and executes the export. World-readable if chmod +x only (remote mode gap — see §4).
${VAR@Q} shell quoting operator for all heredoc interpolations Manual sed/regex escaping, printf '%q' Native Bash 4.4+ operator; produces minimal POSIX-safe single-quoted literals that handle all metacharacters (; | ` $() ' embedded newlines) without custom logic. Requires Bash ≥ 4.4. Not portable to /bin/sh or RHEL 6 / macOS pre-Catalina default shells.
exec bash fallback at end of runner script Exit → auto-close terminal tab Tab stays alive after bob run completes or crashes; developer retains full shell access to inspect working tree state, logs, and git status without reopening a connection. Abandoned tabs hold open SSH connections and consume memory indefinitely until manually closed. Not a problem for small N, but accumulates with repeated runs.
rsync -az --delete for remote input sync scp / manual copy / pre-existing remote files Idempotent and incremental — only transmits changed files. --delete keeps remote bob-shell-inputs/ in exact lockstep with local Inputs/ so agents never read stale guide files. --delete silently removes remote files not present locally. A typo in REMOTE_INPUTS_DIR could delete unexpected data. Path is always derived from WORKSPACE_ROOT (not user-controlled), limiting blast radius.
--no-worktrees flag Always require worktrees Supports read-only, exploratory, or interactive use cases where multiple agents don't need write isolation (e.g., querying history, generating docs). Reduces setup overhead for single-agent runs. All agents share MAIN_DIR — concurrent git mutations from multiple agents will collide. Caller's responsibility to use this flag only for safe workloads.

3 Data Structures, Algorithms & Invariants

In-Memory State — Bash Parallel Arrays

VariableTypeContentsInvariant
tracker_url[] Bash indexed array (declare -a) Tracker URL per agent entry (e.g. https://tracker.ceph.com/issues/12345), or the literal string "none" when absent or explicitly set to none. len(tracker_url) == len(prompt) — arrays grown together in lockstep via tracker_url+=(…) and prompt+=(…) in the same conditional path.
prompt[] Bash indexed array (declare -a) Full prompt string for agent at index i. May be multi-line (directory/.md, Format B); single-line (Format A). Index i → agent i+1. If idx ≥ len(prompt), the agent falls back to interactive bob chat (no prompt assigned).
agent_scripts[] Bash indexed array (declare -a) Absolute paths of staged wrapper scripts: ["/tmp/bob-agent-1.sh", …, "/tmp/bob-agent-N.sh"]. Populated in a single for loop before any Tilix invocation. Length always equals AGENT_COUNT.
AGENT_COUNT Integer scalar max(1, ${#prompt[@]}) Minimum of 1. Guarantees a useful run even with empty/missing instructions (opens one interactive bob chat tab).
IS_LOCAL / USE_WORKTREES / DRY_RUN Boolean integer (0/1) Mode flags derived from CLI args at parse time. Set once; never mutated after the argument parsing loop. Checked as conditions throughout.

Algorithm: Directory Loader (load_from_directory)

Input: directory path Step 1: find -maxdepth 1 -name '*.md' -print0 | sort -z → null-delimited sorted list → files[] (handles spaces in filenames) Step 2: for each file in files[]: Initialize: url="none", body="", in_frontmatter=0, frontmatter_done=0, first_fence=1 Per-line state machine: ┌───────────────────────────────────────────────────────────────────────┐ │ State: BEFORE_FRONTMATTER (frontmatter_done=0, first_fence=1) │ │ line == "---" → in_frontmatter=1, first_fence=0 (enter FM) │ │ line != "---" → treat as body line directly │ │ │ │ State: IN_FRONTMATTER (in_frontmatter=1) │ │ line == "---" → frontmatter_done=1, in_frontmatter=0 (exit FM) │ │ line matches "^tracker: (.*)" → strip quotes → url = value │ │ [[ -n val && val != "none" ]] guards assignment │ │ any other line → ignored (future keys extensible) │ │ │ │ State: BODY (frontmatter_done=1 or first_fence never triggered) │ │ empty line AND body=="" → skip (strip leading blanks from body) │ │ non-empty line → body += line │ └───────────────────────────────────────────────────────────────────────┘ Post-loop: body = sed trim trailing whitespace Guard: [[ -n "$body" ]] → push (url, body); else warn and skip Output: parallel arrays tracker_url[] and prompt[] populated

Algorithm: File Loader — Format A (2-line pairs)

States: EXPECT_URL → EXPECT_PROMPT → EXPECT_URL (cycle) EXPECT_URL: empty line → EXPECT_URL (url reset to "") non-empty → EXPECT_PROMPT (url = line) EXPECT_PROMPT: empty line → EXPECT_URL (orphan URL discarded, url="") non-empty → PUSH(url, line) → EXPECT_URL (url="") EOF: IFS= read -r line || [[ -n "$line" ]] → captures no-trailing-newline final line

Algorithm: File Loader — Format B (Section Delimiter)

Detection trigger: file contains ^## [0-9]+\. OR ```markdown

  • ## N. <title> — starts new entry; title captured as current_url; flushes previous entry if any.
  • Body lines accumulate into current_entry (newline-joined string).
  • --- on its own line — flushes current entry to arrays.
  • Backtick fences (``` / ```markdown) — stripped (not added to body).
  • EOF — flushes any open (unflushed by ---) section.

Script Generation: generate_agent_script(n)

# Pseudocode — reflects actual logic in generate_agent_script()

if USE_WORKTREES:
    dir = MAIN_DIR + "-agent-" + n          # ~/ceph-agent-N  (or ~/Projects/ceph-agent-N local)
    git_checkout_cmd = "git -C ${dir@Q} checkout agent/N"
else:
    dir = MAIN_DIR                           # single repo, no isolation

if idx < len(prompt):
    bob_prompt = tracker_url[idx] + " " + prompt[idx]  # if url != "none"
              OR prompt[idx]                            # if url == "none"
    bob_cmd = "bob run --max-turns 10000 -w ${WORKSPACE_ROOT@Q} -- ${bob_prompt@Q}"
else:
    bob_cmd = "bob chat -w ${WORKSPACE_ROOT@Q}"

# Heredoc written to /tmp/bob-agent-N.sh (local: direct; remote: via ssh "cat >")
#!/usr/bin/env bash
export BOBSHELL_API_KEY=${API_KEY@Q}
cd ${dir@Q}
${bob_cmd}
${git_checkout_cmd}      # empty string when USE_WORKTREES=0
exec bash
Shell safety: Every user-controlled value interpolated into the heredoc uses ${VAR@Q} (Bash 4.4+ parameter transformation). Produces minimal single-quoted literals that handle embedded single-quotes, newlines, semicolons, backticks, and all other shell metacharacters — no custom escaping logic, no regex-based sanitization.
Tracker URL construction: When tracker_url[idx] is not "none" and non-empty, it is prepended to the prompt body separated by a space: "https://tracker.ceph.com/issues/12345 Fix the OSD crash…". This is the entire string passed as the bob run -- '…' argument.

4 Threat Model & Adversarial Handling

Trust Boundaries

[FULLY TRUSTED] [SEMI-TRUSTED INPUT] [SECURE CHANNEL] [LOWER TRUST] Local workstation ←→ Inputs/Prompts/*.md ── SSH/TLS ──▶ Remote /tmp/ (operator shell env) (may contain tracker text from (multi-user public Redmine issues or Linux host, user-authored markdown) sockeni07) ↑ BOBSHELL_API_KEY (env, not file)
Threat Severity Attack Path Mitigation in Code Status
Command injection via prompt or tracker text
Malicious instruction file content:
tracker: https://…; rm -rf ~; #
or multi-line prompt with shell metacharacters 		CRITICAL Prompt/tracker value written into heredoc → sourced by remote bash. Without quoting, semicolons, backticks, $() execute as commands. ${bob_prompt@Q}, ${dir@Q}, ${bob_cmd} (which itself uses ${bob_prompt@Q}) applied to all user-controlled strings before heredoc interpolation. Bash produces safe single-quoted literals neutralizing all shell metacharacters. PROTECTED
API key exposure via world-readable /tmp script (remote)
Another user on sockeni07 reads /tmp/bob-agent-N.sh, which contains export BOBSHELL_API_KEY='…' 		HIGH Remote write: ssh "cat > /tmp/bob-agent-N.sh && chmod +x"
Default umask on many Linux systems = 022 → file mode 0755 (world-readable/executable).		 Local mode applies chmod 700 (correct).
Remote mode uses only chmod +x — no explicit permission restriction.
Recommended fix: replace with:
ssh host "install -m 700 /dev/stdin /tmp/bob-agent-N.sh"
or stage to ~/.cache/bob/agents/ (user-owned, not world-accessible). 		OPEN VULNERABILITY
API key in process argv (ps aux)
Key visible to other users in process table 		MEDIUM If key were a CLI argument to bob run, it would appear in /proc/PID/cmdline and ps aux. Key is always passed via export BOBSHELL_API_KEY=… inside the wrapper script — it lives in the process environment, not argv. Not visible to ps aux. PROTECTED
Frontmatter injection
Attacker places a .md file with a crafted frontmatter that overflows into the body via malformed --- delimiters 		MEDIUM If frontmatter closing --- is absent, the parser stays in in_frontmatter=1 and consumes all remaining lines as key–value pairs. Only tracker: is acted on; other lines are silently ignored. Body becomes empty → file is skipped with a warning. Empty-body guard: [[ -n "$body" ]] before pushing to arrays. Worst case: agent is skipped, not injected. The tracker value itself is passed through ${VAR@Q} at runtime — injection into the shell command is blocked regardless. CONTAINED
rsync --delete misdirected sync
REMOTE_INPUTS_DIR points to wrong path; rsync wipes critical remote files 		MEDIUM REMOTE_INPUTS_DIR="${WORKSPACE_ROOT}/bob-shell-inputs". If WORKSPACE_ROOT were corrupted, the path could become dangerous. WORKSPACE_ROOT is derived from hardcoded defaults or --local flag logic only — it is not user-supplied via CLI. Cannot be set to an arbitrary path by a flag. Path is always a subdirectory of the workspace root. CONTROLLED
Git branch collision between worktrees
Two agents attempt to check out the same branch 		LOW Git enforces single-checkout invariant: a branch already checked out in one worktree cannot be checked out in another — returns fatal: 'branch' is already checked out. Agent N is deterministically bound to agent/N in ceph-agent-N. No dynamic branch selection. Collision requires deliberate misconfiguration of the worktree layout. MITIGATED
Stale /tmp scripts from crashed prior run
Old scripts contain a rotated/invalidated key or stale prompt 		LOW Prior run left /tmp/bob-agent-N.sh with old contents. Scripts are unconditionally overwritten on every run — cat > /path truncates and rewrites. No state persists between runs from these files. PROTECTED

  2. Audit launch plan (zero side effects): ./launch-bob-agents.sh --dry-run --instructions Inputs/Prompts/history-assessment/

# Kill all bob processes for this user

# Clean up /tmp wrapper scripts (also removes stale API key copies)
